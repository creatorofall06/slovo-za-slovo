СЛОВО ЗА СЛОВО — Android-проект на основе прототипа 7

Что внутри:
- www/index.html — игра из прототипа 7 без изменения её игровой логики;
- Capacitor-конфигурация для Android;
- GitHub Actions workflow для автоматической сборки APK.

Как получить APK через GitHub (можно сделать с телефона):
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него ВСЁ содержимое этой папки, включая скрытую папку .github.
3. Откройте вкладку Actions в репозитории.
4. Выберите workflow “Build Android APK” и нажмите Run workflow.
   (Сборка также запускается автоматически после push в ветку main.)
5. Дождитесь зелёного статуса сборки.
6. Откройте завершённый запуск workflow и скачайте artifact
   “slovo-za-slovo-apk”. Внутри будет app-debug.apk.
7. Откройте APK на Android и разрешите установку из этого источника,
   если телефон попросит.

Игра работает локально: игровой экран упакован внутрь приложения,
сервер и интернет во время игры не нужны. Интернет нужен только для
первоначальной загрузки проекта и сборки APK через GitHub.

Важно: это debug APK для личной установки и тестирования. Для публикации
в Google Play позже понадобится release-сборка и подпись приложения.
